# Project Ilion

You're reading this because you're curious about Ilion! That's awesome. Let me tell you about it :)

This website is the result of a community art project that asked over three dozen artists to contribute original character designs. My partner and friend Roby then collected them all and drew additional artwork for the characters. They also created almost all of the art that appears on the site. They hired a graphic designer to create sketches of what the website ought to look like. Then, I created the website from scratch to meet those specifications.

# My Contribution
I was responsible for taking the design created by the graphic designer we hired and making it come to life with CSS and JavaScript. I incorporated a few external plugins (snow, carousel, and ticker) and we hired a contractor to optimize the site for mobile. Besides that, the coding was all me!

I also provided real-time assistance and updates to the website for well over two years, while it underwent frequent changes.
